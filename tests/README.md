# Выполнение учебного проекта

Вариант 15.

Задача:

В проекте всего 20 пунктов задания. Пользователь вводит название проекта и количество пунктов, выполняемых за день: целое число от 1 до 10 включительно.

Программа выводит таблицу за все пять дней. В каждой строке показаны номер дня, выполненный объем, остаток, процент готовности и статус. Выполненный объем не может превышать 20 пунктов. После завершения проекта он остается равным 20.

После таблицы программа выводит итог за пять дней и спрашивает: «Рассчитать другой проект? (да/нет)». Ответ «да» запускает новый расчет с новым вводом данных. Ответ «нет» завершает программу. Любой другой ответ запрашивается снова. Пробелы по краям и регистр букв не влияют на ответ.

## Файлы проекта

- `src/main.py` — код программы;
- `tests/README.md` — проверочные данные и результаты;
- `data/README.md` — описание ввода данных;
- `README.md` — описание проекта и инструкция запуска;
- `requirements.txt` — указание об отсутствии сторонних библиотек;
- `.gitignore` — исключение временных файлов из Git.

## Как запустить

Нужен Python 3.6 или новее. Сторонние библиотеки устанавливать не требуется.

Откройте терминал в папке проекта и выполните: python src/main.py

В Windows можно использовать команду: py src/main.py

В некоторых системах используется команда `python3 src/main.py`.

В поле количества пунктов вводите целое число. Если число меньше 1 или больше 10, программа попросит ввести его снова. Проверка букв, пустого ввода и дробных строк не реализована: для преобразования используется `int()` без обработки исключений.

## Как устроена программа

В программе три функции:

- `task(minimal, maximum)` получает нижнюю и верхнюю границы. Запрашивает количество пунктов за день, проверяет диапазон и возвращает целое число.
- `status(tasks_comp)` получает выполненный объем. Возвращает строку со статусом проекта.
- `table(project_name, tasks_count)` получает название проекта и дневную производительность. Выводит таблицу и итог, спрашивает о повторе и возвращает `True` для «да» или `False` для «нет».

Основной цикл `while repeat` запрашивает исходные данные и вызывает функции. Результат `table()` записывается в `repeat`, поэтому ответ пользователя определяет, начнется ли следующий расчет.

В начале каждого вызова `table()` переменная `tasks_comp` получает значение 0. Поэтому предыдущий проект не влияет на новый.

## Константы и переменные

Значения уровня модуля `project_size = 20` и `all_days = 5` используются как константы и во время работы не изменяются. Их имена оставлены в выбранном для проекта стиле.

- `project_name` — название проекта;
- `tasks_count` — количество пунктов за день;
- `repeat` — признак повторного расчета;
- `tasks_comp` — выполненный объем;
- `tasks_left` — количество оставшихся пунктов;
- `progress` — доля готовности от 0 до 1;
- `project_status` — статус проекта;
- `day` — номер дня;
- `answer` — обработанный ответ о повторе.

`tasks_comp`, `tasks_left`, `progress`, `project_status`, `day` и `answer` внутри `table()` — локальные переменные. Параметры функций тоже локальны. Переменные `project_name`, `tasks_count` и `repeat` в основном цикле находятся на уровне модуля.

## Используемые темы Python

- Простые типы `int`, `float`, `str` и `bool`.
- Ввод и вывод: `input()`, `int()` и `print()`.
- Арифметические операции, сравнения и составные выражения.
- Условия `if–elif–else` для определения статуса.
- Логические операторы `or` и `and` для проверки ввода.
- Цикл `for` с `range()` для расчета всех пяти дней.
- Циклы `while` для проверки диапазона, проверки ответа и повторного расчета.
- Три функции с параметрами и `return`, строки документирования.
- F-строки для оформления таблицы и отчета.
- `.strip().lower()` для обработки ответа.

Заголовки расположены по центру поля шириной 60 символов. Подписи выровнены слева, числовые значения — справа. Номера дней выводятся с ведущим нулем, проценты — с одним знаком после точки. Для формата `.1%` используется доля `tasks_comp / project_size`, без предварительного умножения на 100.

Денежных показателей в этом варианте нет. Списки, кортежи, словари, множества, классы, работа с файлами и импорты в программе не используются.

## Проверка программы

Проверены обычные и граничные значения производительности, неверные числа вне диапазона, повторный расчет, неверный ответ на вопрос о повторе, пробелы и регистр в ответах. Сценарии и результаты находятся в `tests/README.md`.

## Как загрузить на GitHub

Создайте пустой открытый репозиторий `python-module1-final`. В терминале из папки проекта выполните команды для двух осмысленных коммитов:

```bash
git init
git add src/main.py
git commit -m "Добавлена программа прогноза по варианту 15"
git add README.md tests/README.md data/README.md requirements.txt .gitignore
git commit -m "Добавлены описание проекта и результаты проверок"
git branch -M main
```

Добавьте адрес своего репозитория, заменив `YOUR_LOGIN` на логин GitHub:

```bash
git remote add origin https://github.com/YOUR_LOGIN/python-module1-final.git
git push -u origin main
```

Если Git попросит имя и email автора коммитов, укажите свои данные. Проверьте доступность репозитория и наличие обоих коммитов. Для сдачи задания отправьте ссылку на репозиторий в Google Class.
